# Инструмент визуализации графа зависимостей (Вариант №9)

## Общее описание
CLI-приложение для анализа и визуализации графа зависимостей пакетов
формата Alpine Linux (apk) без использования сторонних библиотек.

## Функции и настройки
Параметры командной строки:
- `--package` — имя анализируемого пакета (обязательный).
- `--repo` — URL репозитория Alpine или путь к файлу (обязательный).
- `--test-mode` — включение режима тестового репозитория (флаг).
- `--version` — версия анализируемого пакета (обязательный).
- `--output` — имя выходного SVG-файла (по умолчанию `graph.svg`).

## Команды запуска и тестов
Запуск приложения на Windows:
```bat
run.bat --package curl --repo https://alpinelinux.org --version 8.9.1-r0
```

Запуск модульных тестов:
```bat
python -m unittest discover -s tests
```
